# Участие в разработке

Нужны Node.js 22.12+ и npm. Для сборки macOS нужен Mac.

```sh
npm ci
npm test
npm run desktop
```

При изменении поведения сначала добавь тест, проверь ожидаемое падение, затем исправь код. Для интерфейса проверь реальные действия и скриншоты в приложении.

Pull request должен объяснять проблему, результат и выполненные проверки. Не добавляй личные документы, подключения проектов, токены или рабочее состояние Horizon. Для воспроизведения используй временную рабочую папку:

```sh
HORIZON_USER_DATA="$(mktemp -d)" npm run desktop
```
