# Подключение агентов

Horizon хранит поручение и результат, а работу выполняет твой агент. Аккаунт и вход остаются в приложении или CLI провайдера. Поля для общего API-ключа в Horizon нет.

## Начать с любого агента

1. Создай задачу во вкладке «Агенты». Выбери проект и напиши конкретное поручение.
2. Нажми **«Скопировать задачу»** и вставь текст в Codex, Claude Code, Z.ai или другой инструмент, которому ты доверяешь этот проект.
3. В поручении будут пути к рабочей папке, инструкции и номер задачи. Агент сможет прочитать их и обновить свою строку через CLI Horizon. Для запуска этих CLI-скриптов агенту нужен Node.js 22.12+.
4. Обсуждай результат в колонке «Твой комментарий». После проверки нажми «Принять» у показанной версии результата.

Копирование не отправляет сообщение провайдеру. Ты выбираешь, куда вставить текст и какие разрешения дать агенту. Текст поручения может содержать твои комментарии и пути; проверь его перед передачей.

## Codex

Установи Codex и войди в свой аккаунт по [официальной инструкции](https://developers.openai.com/codex/cli). Horizon ищет исполняемый CLI в пользовательском каталоге, PATH, стандартных папках Homebrew и установленном Codex.app. Другой путь можно задать через `HORIZON_CODEX_BIN` при запуске из Terminal.

В Horizon:

1. Открой ⋯ рядом с **«Сессии»** и нажми **«Обновить сессии Codex»**.
2. У нужной задачи открой ⋯ → **«Исполнитель»**. Выбери найденную сессию либо укажи Codex и её ID. Нажми **«Сохранить исполнителя»**.
3. Нажми имя сессии, чтобы открыть её в Codex, или **«Скопировать задачу»**, чтобы передать поручение вручную.

Кнопка **«Отправить»** для Codex использует экспериментальную очередь App Server. Совместимость зависит от версии Codex. «Queued» подтверждает запись в очередь, а не начало работы. Полная доставка и выполнение не сертифицированы для произвольной установки Codex; для первого знакомства используй копирование. Разрешения и вопросы решаются в Codex.

[App Server](https://developers.openai.com/codex/app-server) предоставляет интерфейс для собственной интеграции с авторизацией, историей и разрешениями. Полноценный вход в Codex из Horizon пока не реализован.

## Claude Code, Z.ai и другие

Через ⋯ у задачи можно выбрать провайдера и записать ID сессии. Это связь для учёта работы; автоматический запуск и доставка для этих провайдеров не подключены. Передавай текст кнопкой «Скопировать задачу».

Для автоматической регистрации агент может вызвать установленный скрипт:

```sh
node /Applications/Horizon.app/Contents/Resources/app/scripts/agent-session.mjs register \
  --root /absolute/path/to/workspace --project local \
  --provider codex --title "Название задачи" --task T01
```

Для Codex ID берётся из `CODEX_THREAD_ID`. Если агент работает в другой среде, нужен его настоящий ID через `--session`. Номера задач и сессий нельзя выдумывать. Для подключённого проекта вместо `local` используется его ID из настроек Horizon.

## Что стоит взять у Verticals

У [Verticals](https://github.com/konstantinopolskii/verticals/blob/main/desktop/README.md#menu-bar) есть отдельные команды подключения Claude Code и Codex через MCP. Они изменяют настройки агента только после клика пользователя. Для Horizon это следующий отдельный шаг: локальный MCP-интерфейс, явное подключение и проверяемое состояние. Сейчас Horizon не устанавливает MCP-сервер в чужие настройки.
