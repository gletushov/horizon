# Что подсмотрели у Verticals

Источники: [репозиторий](https://github.com/konstantinopolskii/verticals), [PR №65](https://github.com/konstantinopolskii/verticals/pull/65), [правила PR](https://github.com/konstantinopolskii/verticals/blob/main/.agents/skills/verticals-pr/SKILL.md), [меню подключения](https://github.com/konstantinopolskii/verticals/blob/main/desktop/README.md#menu-bar), [проект сценария сообщений об ошибках](https://github.com/konstantinopolskii/verticals/blob/main/docs/design/bug-reports.md). Проверено 19.10.2026.

| Область | Verticals | Horizon |
|---|---|---|
| Изменения | Одна задача в PR; описание проблемы/решения либо результата; проверки; для больших изменений — порядок чтения | Эти принципы включены в CONTRIBUTING и шаблон PR |
| Проверка PR | Проверка формы в CI и отдельное чтение агентом Claude через их инструмент | Тесты и проверка пакета в CI; TDD и финальное ревью. Обязательной зависимости от Claude для отправки PR нет |
| Скриншоты | Видимые изменения показываются на синтетических данных | Скриншоты инструкции создаются в отдельном временном workspace |
| Агенты | Команды меню подключают Claude Code и Codex к локальному MCP по явному действию пользователя | CLI обнаруживается автоматически; сессия назначается задаче. Универсальная передача — копирование. MCP-подключение пока следующий шаг |
| Сообщения об ошибках | Описан сценарий: сначала отчёт с картинками, затем явная отправка в GitHub или работа агента над улучшением | Меню открывает форму GitHub Issue. Пользователь выбирает, что отправить, и сам публикует сообщение |

Что стоит развивать дальше: отдельный проверяемый экран состояния агента, подключение через MCP только по клику и локальный черновик отчёта об ошибке с предварительным просмотром вложений. Эти пункты — предложения; в текущем релизе они не заявлены как реализованные.

Horizon сохраняет собственную реализацию. Заимствованы идеи организации работы и принципы описания изменений; исходный код Verticals и его инструменты в этот репозиторий не переносились в рамках этой работы.
